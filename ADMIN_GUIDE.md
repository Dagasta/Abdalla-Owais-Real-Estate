# Admin Guide - Abdalla Alowais Real Estate

This guide will help you manage your real estate website effectively.

## Accessing the Admin Dashboard

1. Navigate to: `https://yourwebsite.com/admin/login`
2. Enter your email and password
3. Click "Sign In"

## Dashboard Overview

After logging in, you'll see:
- **Total Properties**: All properties in the system
- **Available Properties**: Properties currently for sale/rent
- **Total Inquiries**: All inquiries received
- **New Inquiries**: Unread inquiries

## Managing Properties

### Adding a New Property

1. Click **"Add Property"** button
2. Fill in the required information:
   - **Title**: Property name (e.g., "Luxury 3BR Apartment in Al Majaz")
   - **Description**: Detailed property description
   - **Price**: Property price in AED
   - **Location**: Area/neighborhood in Sharjah
   - **Type**: Select "For Sale" or "For Rent"
   - **Bedrooms**: Number of bedrooms
   - **Bathrooms**: Number of bathrooms
   - **Area**: Property size in square feet
   - **Images**: Upload property photos (minimum 1 required)
   - **Amenities**: Add features (e.g., "Swimming Pool", "Gym", "Parking")
   - **Status**: Usually "Available"

3. Click **"Submit"** to publish the property

### Editing a Property

1. Go to **"Properties"** in the sidebar
2. Find the property you want to edit
3. Click **"Edit"** button
4. Update the information
5. Click **"Save Changes"**

### Deleting a Property

1. Go to **"Properties"** in the sidebar
2. Find the property you want to delete
3. Click **"Delete"** button
4. Confirm the deletion

> ⚠️ **Warning**: Deleted properties cannot be recovered!

### Changing Property Status

You can mark properties as:
- **Available**: Actively listed
- **Sold**: Property has been sold
- **Rented**: Property has been rented

This helps keep your listings up to date.

## Managing Inquiries

### Viewing Inquiries

1. Click **"Inquiries"** in the sidebar
2. You'll see all inquiries with:
   - Customer name
   - Email address
   - Phone number
   - Message
   - Property they inquired about (if applicable)
   - Date received

### Responding to Inquiries

1. Note the customer's contact information
2. Respond via:

### Inquiry Status

Mark inquiries as:

## Best Practices

### Property Listings

✅ **DO:**
- Use high-quality, well-lit photos
- Write detailed, accurate descriptions
- Include all amenities
- Update status promptly when sold/rented
- Use competitive pricing

❌ **DON'T:**
- Use blurry or low-quality images
- Exaggerate property features
- Leave outdated listings as "Available"

### Photos

- **Minimum**: 1 photo (required)
- **Recommended**: 5-10 photos
- **Include**: 
  - Exterior view
  - Living room
  - Bedrooms
  - Kitchen
  - Bathrooms
  - Amenities (pool, gym, etc.)

### Pricing

- Research market rates in Sharjah
- Price competitively
- Update prices if market changes
- For rentals, specify if price is monthly/yearly

### Responding to Inquiries

- **Response Time**: Within 24 hours (faster is better!)
- **Be Professional**: Use proper grammar and tone
- **Be Helpful**: Answer all questions thoroughly
- **Follow Up**: If no response, follow up after 2-3 days

## Troubleshooting

### Can't Login?
- Check your email and password
- Ensure you're using the correct admin email
- Contact support if password reset needed

### Property Not Showing?
- Check the status is set to "Available"
- Verify all required fields are filled
- Refresh the website

### Not Receiving Inquiry Emails?
- Check spam/junk folder
- Verify email address in settings
- Ensure Resend API is configured

### Images Not Uploading?
- Check file size (max 5MB recommended)
- Use JPG, PNG, or WebP formats
- Ensure stable internet connection
